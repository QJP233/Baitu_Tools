# Baitu_Tools

> 实验室家具设计 / 拆单工具集。当前包含 **中央台快速拆单**（全钢 · 钢木 · 不锈钢）。

纯前端单文件工具，无需安装、无需后端、不联网即可使用；双击 HTML 即可打开，也可直接部署为静态站点。

## 功能概览

| 模块 | 能力 |
|---|---|
| 尺寸换算 | 输入台面尺寸，自动扣除四边镶边得到净柜体尺寸 |
| 水柜扣除 | 水柜固定端头，扣除后得到可用排柜长度 |
| 空位计算 | 按空位率公式计算空位数，空位宽度 500–800mm 弹性伸缩 |
| 柜体排布 | 先大后小：900 双柜优先，450 单柜补齐 |
| 排布约束 | 标准模式（空位互不相邻）/ 严格模式（空位仅限异规格柜体之间） |
| 规格库 | 全钢 / 钢木 / 不锈钢 三种材质，各自独立的水柜、双柜、单柜、空位规格与成本指数 |
| 方案比选 | 多方案成本指数对比、规格种类对比，标注「成本最优」「标准库」 |
| 俯视图 | 按真实比例绘制的技术图纸：双面对称柜体、门缝拉手、水槽龙头、尺寸链 |
| 输出 | 一键复制拆单清单、打印 / 存 PDF |

## 使用说明

1. **选择台面材质**：全钢 / 钢木 / 不锈钢。切换后会自动加载该材质对应的产品规格与成本指数。
2. **输入台面尺寸**：长 × 宽，单位为 mm。这里的尺寸是**台面尺寸**（已包含四边外挑的沿边）。
3. **选择水柜配置**：无 / 单端 / 双端。水柜位置固定，不可调整。
4. **选择空位率**：30%（基准）/ 35% / 40%。
5. **选择柜体布置**：双面对称 / 单面。
6. **查看结果**：顶部为主结果（柜体组合）与关键尺寸，中部为俯视图，下部为拆单清单。
7. **输出**：点「复制清单」可粘贴到 Excel / 微信；点「打印 / PDF」输出图纸与清单。

左侧预设条最前面的红色 **「最小 xxxx」** 是当前配置下含空位的最小可行台面长度，点击可直接套用。

## 拆单规则（算法口径）

### 1. 台面与镶边

- 标准中央台宽度 **1500mm**，基于人体工程学单侧操作深度 750mm 确定。
- 长度方向两端镶边**实际 25mm**，计算时统一按 **30mm** 扣除。
- 例：4500 − 60 = **4440mm** 净柜体长度；宽度 1500 − 60 = **1440mm**。

### 2. 水柜与可用长度

- 全钢水柜深度 **700mm = 520mm 柜体 + 180mm 延伸**。
- 水柜固定于端头，位置不可调整；扣除后剩余长度用于排布标准柜体与空位。
- 例：4440 − 700 = **3740mm** 可用排柜长度。

### 3. 空位数量

```
空位数 = ROUND（可用长度 × 空位率 ÷ 500mm）
```

- 30% 为空位率基准值，实际可上浮至 **40%**，前提是单个空位宽度不超过 800mm。
- 单个空位 **最小 500mm**（低于此值腿部空间不足），**最大 800mm**（超过易被质疑偷工减料）。

### 4. 柜体排布

- **先大后小**：优先排布 900mm 双柜，再用 450mm 单柜补齐。
- 空位宽度在 500–800mm 内弹性伸缩，用于适配整数柜体组合。
- **标准模式**：空位均匀落在柜体接缝上，不靠端头、不出现连续两个空位（同规格柜体之间允许放空位）。
- **严格模式**（可选）：空位只能夹在两个**不同规格**的柜体之间，即 `双柜–空位–单柜–空位–双柜` 或 `单柜–空位–双柜–空位–单柜`。

### 5. 多方案比选

- 成本指数 = 双柜数量 × 双柜指数 + 单柜数量 × 单柜指数（空位与水柜各方案相同，不计入）。
- 同时统计**柜体规格种类**：种类越多，库房管理与生产换型成本越高。
- 默认成本指数：全钢 100 / 58，钢木 78 / 46，不锈钢 145 / 84（仅为相对指数，非实际金额，可在「规格参数」中调整）。

### 6. 标准算例（4500mm 单端水柜，全钢）

| 方案 | 柜体组合 | 空位 | 成本指数 | 规格种类 |
|---|---|---|---|---|
| A（标准库） | 3 × 900 双柜 | 2 × 520 | 300 | 1 种 |
| B（成本最优） | 2 × 900 双柜 + 1 × 450 单柜 | 2 × 745 | 258 | 2 种 |

## 技术说明

- **零依赖**：所有 CSS / JavaScript 内联在单个 HTML 文件中，不加载任何外部资源，离线可用。
- **无构建**：不需要 Node.js、打包器或包管理器。
- **无数据外发**：所有计算在浏览器本地完成，不上传任何数据。
- **固定视口布局**：整屏无滚动，图纸区域自适应高度；适配 1024×768 ~ 1920×1080。
- **浏览器要求**：Chrome / Edge / Safari 等现代浏览器（需支持 CSS 自定义属性、Grid、SVG）。

核心算法集中在 `index.html` 的 `CORE-BEGIN` ~ `CORE-END` 区块，包含：

- `splitEven(total, n)` — 余量按 5mm 步长均分，尾差以 1mm 补齐，保证合计精确闭合
- `findSolutions(Lr, n, cfg)` — 枚举 (双柜 k, 单柜 m) 组合
- `maxSlots(k, m, strict)` — 该组合可容纳的空位上限
- `arrange(k, m, slots, strict)` — 生成排布序列，保证空位不相邻

## 常见问题

**Q：为什么某些尺寸提示「无法拆单」？**

柜体总长只能由 900 与 450 组合而成（即 450 的整数倍），空位又限定在 500–800mm，因此可行长度是离散区间，会出现空隙（例如 3000mm 单端水柜）。提示框会给出最近的可行的台面长度，一键套用即可。

**Q：清单里的「×2」是什么意思？**

双面对称布置时，同一规格柜体在两侧各有一套，所以数量 = 单侧数量 × 2。水柜本身贯通整个深度，不翻倍；空位是布局位，也不翻倍。

**Q：成本指数是报价吗？**

不是。它是用于方案之间横向比较的相对权重，可在「规格参数」中按实际成本结构修改。

**Q：可以加更多材质吗？**

可以。在 `index.html` 中搜索 `DEFAULT_SPECS`，按现有结构追加一种材质即可（需同时补充左侧材质切换按钮）。
